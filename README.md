I build games and the tools to make them: my own engine, no heavy dependencies,
hand-built until it works the way I want. I also write, and I publish small,
focused open-source Python libraries. Everything lives under
**[Lianes8 Studio](https://lianes8studio.com)**, shipped in 31 languages.
